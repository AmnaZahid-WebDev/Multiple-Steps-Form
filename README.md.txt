# Multiple Steps Form

A simple multi-step review form created using HTML5 and CSS3.

## Features

- 3-step form
- Account Details section
- Personal Details section
- Review section
- Navigation between all three pages
- Email and password fields
- CNIC input fields
- Social profile link field
- Radio buttons
- Comments textarea
- File upload option
- Email updates checkbox
- Back and Next navigation buttons

## Technologies Used

- HTML5
- CSS3

## Pages

1. `index.html` – Introduction page
2. `account.html` – Account Details
3. `personal.html` – Personal Details
4. `review.html` – Your Review

## Purpose

This project was created as part of an HTML and CSS assignment to practice creating forms, linking multiple pages, and applying basic CSS styling.
